功能 下载 说明

Windows 悬浮窗查词工具

雅思复盘时，复制单词就能查释义并存入生词本。

适合做题复盘、精听精读和整理错题时使用。小窗口常驻桌面，自动读取剪贴板里的英文单词，保存结果到 Excel。

下载 Windows EXE 下载文本模型包 下载图片模型包
01

复制后自动查词

复制英文单词后自动触发查询，也支持直接在窗口里输入单词或短语。

02

保存到 Excel 生词本

把单词和释义保存到指定 Excel，方便继续筛选、打印或复习。

03

支持快捷键操作

支持保存、备份、打开生词本等快捷键，复盘时尽量少打断思路。

AI 翻译模式

新版支持接入本机 Ollama 大语言模型。单词仍然优先查内置离线词库；句子、段落可通过文本模型翻译，图片可通过视觉模型识别并翻译。模型与软件分开下载，用户安装模型后软件会自动检测。

推荐模型 qwen2 + llava 文本翻译 + 图片翻译

安装与使用

下载后双击运行 EXE。首次打开时选择新建或导入 Excel 生词本。若全局快捷键不生效，请右键选择“以管理员身份运行”。

当前版本 v1.1.1 支持 Windows
